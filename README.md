# EcoColecta

## Descripción
EcoColecta es una aplicación web destinada a gestionar puntos de reciclaje comunitario y registrar las entregas de materiales reciclables realizadas por los ciudadanos.

## Investigación: Evolución del Control de Versiones

### Sistemas Centralizados (SVN)
Los sistemas centralizados como SVN almacenan el historial del proyecto en un servidor central. Los desarrolladores deben conectarse a dicho servidor para enviar o descargar cambios.

Ventajas:
- Administración centralizada.
- Fácil control de permisos.

Desventajas:
- Dependencia del servidor.
- Menor flexibilidad para trabajar sin conexión.

### Sistemas Distribuidos (Git)
Git permite que cada desarrollador tenga una copia completa del repositorio, incluyendo todo el historial.

Ventajas:
- Trabajo sin conexión.
- Mayor velocidad.
- Mejor manejo de ramas y fusiones.

Desventajas:
- Curva de aprendizaje inicial.

## Diferencia entre Git y GitHub

### Git
Es una herramienta de control de versiones distribuido instalada localmente en la computadora.

Funciones:
- Crear commits.
- Gestionar ramas.
- Fusionar cambios.
- Mantener historial del proyecto.

### GitHub
Es una plataforma en la nube que aloja repositorios Git.

Funciones:
- Almacenamiento remoto.
- Trabajo colaborativo.
- Pull Requests.
- Issues.
- GitHub Actions.
